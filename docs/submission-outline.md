## 슬라이드 3. 서비스 핵심기능

- 카카오 / 구글 소셜 로그인
- 스와이프 기반 온보딩 취향 분석 (사진 좋아요/싫어요로 7개 감성태그 취향 벡터 산출)
- AI 개인화 여행 코스 추천 (취향 벡터 → 유사 장소 검색 → 숨은 장소 가중치 → 방문 순서 최적화)
- 직접 여행 코스 만들기 (장소 직접 선택, 여러 날 일정 지원)
- 장소 탐색 (카테고리별 목록, 검색, 안동 지역 지도 탐색)
- 방문 기록 작성 ("나의 일지" — 사진·한줄리뷰·평점·날씨 기록, 첨부 사진은 AI가 자동으로 감성 태그 분석, 장소 여러 곳을 하나의 코스로 묶어 기록 가능)
- 취향이 비슷한 다른 사용자의 코스·기록 탐색
- 스크랩북 (찜한 장소 / 저장한 코스 모아보기)
- 행사·축제 정보 제공 (진행 기간 기준 노출)
- 비로그인(게스트) 이용 지원 — 장소 탐색·검색·행사 정보는 로그인 없이도 이용 가능

> 위 목록은 §1~§9 전체 검토 완료 기준(2026-09-08)

## 슬라이드 6. 서비스 핵심 기능별 흐름도

> PPT에서는 이 섹션을 기능당 1페이지씩 복사해서 채움(최대 5개). 아래는 후보 기능과 단계 초안 — 실제 스크린샷은 각자 붙여야 함.

### 핵심기능 1 — AI 개인화 여행 코스 추천
**기능 설명**: 스와이프로 가고 싶은 장소를 고르면, 취향 벡터와 장소의 감성 데이터를 매칭해 방문 순서까지 최적화된 여행 코스를 자동으로 만들어주는 기능
**흐름**:
1. [TBD 스크린샷] 홈 화면에서 "AI로 코스 만들기" 선택
2. [TBD 스크린샷] 후보 장소 카드 20장을 좋아요/싫어요로 스와이프
3. [TBD 스크린샷] 취향 벡터 기반으로 추천된 장소들의 방문 순서·이동 경로가 계산된 코스 결과 확인
4. [TBD 스크린샷] 코스 저장 (스크랩북에서 다시 확인 가능)

### 핵심기능 2 — 온보딩 취향 분석
**기능 설명**: 최초 가입 시 장소 사진을 스와이프하며 사용자의 감성 취향(7개 대분류)을 학습하는 기능
**흐름**:
1. [TBD 스크린샷] 회원가입 직후 온보딩 카드 노출
2. [TBD 스크린샷] 카드를 좋아요(오른쪽)/싫어요(왼쪽) 스와이프, 실시간으로 취향 벡터 갱신
3. [TBD 스크린샷] 취향이 충분히 파악되면(최소 15장 이후 변화량 수렴, 늦어도 25장) 자동 종료 후 홈 화면 진입

### 핵심기능 3 — 방문 기록 (나의 일지)
**기능 설명**: 실제 방문한 장소에 사진과 후기를 남겨 개인 여행 기록을 쌓는 기능
**흐름**:
1. [TBD 스크린샷] 홈 화면 "나의 일지" 탭에서 "+" 선택
2. [TBD 스크린샷] 장소 선택, 사진 첨부(여러 장), 제목·한줄리뷰·날씨·방문일 입력 후 저장
3. [TBD 스크린샷] 저장된 기록이 카드 목록으로 누적 표시, 이후 평점 추가 가능

### 핵심기능 4 — 장소 탐색
**기능 설명**: 카테고리별로, 또는 검색으로 안동의 장소를 둘러보고 상세 정보(영업시간·사진·방문 후기)를 확인하는 기능
**흐름**:
1. [TBD 스크린샷] "안동 거리" 탭에서 카테고리 아이콘 선택 또는 상단 검색 사용
2. [TBD 스크린샷] 카테고리·검색어에 맞는 장소 목록 확인
3. [TBD 스크린샷] 장소 선택 시 대표 이미지·영업시간·방문자 후기가 담긴 상세 화면 진입

### 핵심기능 5 — 취향 맞춤 코스 (비슷한 취향 탐색)
**기능 설명**: 나와 취향이 비슷한 다른 사용자들이 저장한 코스와 방문 기록을 둘러보는 기능
**흐름**:
1. [TBD 스크린샷] 홈 화면 "취향 맞춤 코스" 탭 진입
2. [TBD 스크린샷] 취향이 겹치는 사용자의 코스/기록 카드 목록 확인
3. [TBD 스크린샷] 카드 선택 시 지도에 경로/위치 미리보기, "자세히 보기"로 상세 확인

## 슬라이드 9. 서비스 차별성 & 발전계획

| 항목 | 내용 |
|---|---|
| 차별성 | **[TBD 초안]** (1) 텍스트 후기나 별점이 아니라 **사진 자체를 AI가 분석**해 만든 감성 태그로 취향을 정량화 — "여유로운", "포토제닉한" 같은 추상적 취향을 실제 데이터로 매칭. (2) 방문 로그가 적고 대표 관광지가 아닌 "숨은 장소"에 가중치를 주는 `hidden_score` 로직으로, 하회마을·병산서원 같은 뻔한 장소 위주가 아닌 추천 제공. (3) 안동이라는 단일 지역에 집중해 데이터 밀도와 추천 정확도를 높임 |
