## 기능 스펙

### 인증
- 소셜 로그인: 카카오, 구글. 이 외 로그인 방식 없음
- **비로그인(게스트) 이용**(2026-09-08 확정): 로그인 없이도 장소 목록/검색/상세(전 카테고리), 행사·축제 목록, 감성 태그 안내, 안동 거리 탭(카테고리 탐색)은 이용 가능. 그 외 기능(나의 일지, 취향 맞춤 코스, 코스 만들기·스크랩북, 방문 기록 작성, 알림 설정, 프로필)은 로그인 필요

### 내 정보
- 이메일: 회원가입 시 소셜 이메일 그대로, 수정 불가
- 사용자ID: 중복 불가
- 닉네임: 중복 허용

### 내 취향 프로필
- 감성태그 7개 대분류 점수를 7각형 레이더 차트로 시각화 (0.5 중립 기준선)
- '내 취향 다시 분석하기' 버튼 → 온보딩 재시작

### 스크랩북 (2026-09-08 정식 반영)
- 내가 찜한 장소와 저장한 코스를 한 화면에서 모아보는 기능 (여행코스 탭 / 관광지 탭)

### 온보딩
- 사용자에게 장소 사진을 보여주고 오른쪽(좋아요)/왼쪽(스킵) 스와이프
- **종료 조건** (둘 중 하나 충족 시 종료):
  1. 최근 3장 벡터 변화량 평균 < 0.03 AND 최소 15장 진행 (수렴 종료)
  2. 총 25장 도달 (강제 종료)
  - 예외: 좋아요 3개 미만이면 최소 15장까지 강제 진행
- **카드 선택 전략**: 시드 7장(태그별 대표 1장) → 균형 60% + 탐색 30% + 랜덤 10%
- **벡터 업데이트**: 좋아요 학습률 0.40 / 싫어요 0.25 (상대적 업데이트 방식)
- **카드 풀 규모**(2026-09-08 확정): 현재 78장(서로 다른 장소 58곳 커버) 규모 유지
- 세부 명세: `server-back/Onboarding Algo.md` (v2.0.0)

### 장소 탐색
- 카테고리별(관광지/식당/카페/액티비티/문화공간/축제행사) 장소 목록을 카드 UI로 제공, 이름 검색 가능
- 장소 상세: 대표 이미지, 사용자 사진, 한줄 리뷰, 분위기 태그, 영업시간 확인 가능
- 행사·축제는 사용자의 여행 예정일과 기간이 일치할 때만 노출 (기간 한정 표시)
- **안동 거리 탐색**(2026-09-08 확정, 기존 "카테고리 탐색 지도" 계획에서 방식 변경): 실제 GPS 좌표 기반 지도가 아니라, 안동 지역 일러스트(3D, 드래그 회전 가능) 위에 카테고리별 아이콘을 배치해서 탐색하는 방식

### 방문 기록
- 방문 장소에 제목, 사진(여러 장, 사진별 캡션 포함), 한줄 리뷰, 날씨, 별점(1~5), 방문일을 기록 (2026-09-08 확정 — 별점은 최초 작성이 아니라 이후 수정 화면에서 매김)
- 업로드된 사진은 AI가 감성 태그셋 기준으로 분석해 그 기록의 감성 태그 데이터로 반영 (데이터 파트 배치 작업으로 구현 완료, 2026-09-08)
- 기록은 "나의 일지"에 카드 목록으로 누적. 공개로 설정된 기록은 취향이 비슷한 다른 사용자에게도 노출됨
- **코스 단위 기록**: "기록하기"에서 장소를 2개 이상 고르면 `visit_log.course_id`로 묶인 코스(`course.source='journal'`)로 저장됨. 여행 날짜는 범위 선택(여러 날도 가능), 사진/제목/한줄리뷰/날씨/별점/방문일은 장소마다 각각 입력(장소 단위 감성태그 분석은 그대로 유지). 이렇게 만들어진 코스도 스크랩북 "내 코스" 목록에 AI/직접 코스와 동등하게 노출됨 (2026-09-08 결정, 2026-09-10 재확인, decision-log 참고)

### 취향 맞춤 코스 탐색 (2026-09-08 정식 반영, 기존 "지도" 계획에서 개편)
- 취향이 비슷한 다른 사용자가 저장한 **공개 코스**와 **개별 방문 기록**을 카드 목록으로 탐색
- 카드를 고르면 그 코스/장소의 실제 좌표 기반 지도 미리보기(경로 또는 마커)를 보여주고, 이어서 상세 화면으로 이동 가능
- 실제 GPS 좌표 기반 지도는 이 미리보기와 코스 상세 화면에서만 사용 — 나머지 탐색(나의 일지, 안동 거리)은 위 "안동 거리 탐색"과 같은 장식용 지구본 방식

### 코스 추천
- 스와이프로 가고 싶은 장소 선택 → 필수 방문 장소 지정 가능
- AI 코스 후보 **1개** 생성 (2026-09-08 확정, 기존 "3개 생성" 계획에서 변경) — 이동거리·영업시간·숨은 장소 가중치 고려
- 여행 시간대는 사용자가 조정 가능 (2026-09-08 확정, 2026-09-09 구현 완료)
- 여행 출발 위치는 사용자가 조정 가능해야 함 (2026-09-08 확정, 구현은 아직)
- **AI 코스도 여러 날(N박N일) 지원** (2026-09-10 확정, 기존 "AI 코스는 하루짜리" 방침에서 변경) — 날짜마다 코스 추천을 따로 돌려 이어붙이는 방식, 같은 장소가 여러 날 중복되지 않게 함
- **직접 코스 만들기**(2026-09-08 정식 반영, 신규): 사용자가 장소를 직접 선택해 코스를 구성, 여러 날(N박N일) 일정도 지원
- 숨은 장소 우선 반영 (방문 로그 수 적고 대표 관광지 아닌 장소)
- 코스 저장 가능 (장소 목록 + 방문 순서 보관). 저장한 코스는 기본적으로 공개 상태이며, 공개 여부를 사용자가 직접 설정하는 기능은 이번 범위에 없음 (2026-09-08 확정)

### 알림 (2026-09-08 확정)

## 감성태그셋

사진 분위기 기반으로 취향 파악 → 비슷한 분위기 장소 추천에 사용.
모든 사진과 사용자는 아래 7개 태그의 독립적인 0.0~1.0 점수 벡터를 가진다.

### 대분류 7개 (확정)

| 키 | 설명 | AI 판단 기준 (5가지) |
|---|---|---|
| `relaxing` | 여유, 힐링, 조용함 | 한적함 있음 / 조용한 분위기 있음 / 개방감 있음 / 자연 요소 있음 / 오래 머물고 싶은 분위기 있음 |
| `lively` | 활기참, 북적임 (시장, 축제) | 사람 밀집도 높음 / 활동적인 분위기 있음 / 상업적 활기 있음 / 축제·행사 분위기 있음 / 에너지 있는 분위기 있음 |
| `romantic` | 데이트, 감성, 야경 | 함께 시간을 보내기 좋은 분위기 / 따뜻한 색감 있음 / 아늑한 분위기 있음 / 감성적인 연출 요소 있음 / 특별한 추억을 만들고 싶은 분위기 있음 |
| `local` | 동네감성, 숨은명소 | 지역 고유의 분위기 있음 / 생활감 있는 공간 있음 / 지역 문화 요소 있음 / 지역만의 개성 있음 / 소박한 분위기 있음 |
| `photogenic` | 사진 찍기 좋은 | 좋은 사진 구도 있음 / 아름다운 배경 있음 / 매력적인 색감·조명 있음 / 시선을 끄는 포인트 있음 / 사진으로 남기고 싶은 장면 있음 |
| `traditional` | 전통적인, 역사적인, 한국적인 감성 | 전통적인 분위기 있음 / 역사적인 분위기 있음 / 한국적인 감성 있음 / 고즈넉한 분위기 있음 / 문화유산적인 분위기 있음 |
| `modern` | 현대적인, 세련된, 트렌디한 분위기 | 현대적인 건축 요소 / 도시적인 분위기 있음 / 세련된 디자인 / 트렌디한 공간 / 현대적인 감성이 있음 |

> `traditional`과 `modern`은 합이 1이 아닌 독립적인 점수. 한옥 카페처럼 두 태그가 모두 높은 복합 공간이 존재하기 때문.
