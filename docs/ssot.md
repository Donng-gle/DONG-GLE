## 서비스

- 서비스명: 동글
- 대상 지역: 경상북도 안동시
- 핵심 기능: 감성태그 기반 개인화 여행 코스 추천

## 팀 구성

| 이름 | 파트 | 주요 역할 |
|---|---|---|
| 이수연 | 데이터 | TourAPI 수집, DB 적재, 감성태그 분석 파이프라인 |
| 설만수 | 프론트+백엔드 | REST API 서버, 앱/웹 UI 구현, 인증 |
| 김지광 | 알고리즘+LLM | 코스 추천 알고리즘, LLM 프롬프트 설계 |
| 전성빈 | 디자인 | UI/UX 디자인 |

## TourAPI (기준 정보)

- Base URL: `https://apis.data.go.kr/B551011/KorService2/`
- 안동시 코드: `lDongRegnCd=47`, `lDongSignguCd=170`
- API 키 위치: `.env` → `TOURAPI_KEY`

### 수집 대상 (contentTypeId)

| 12 | 관광지 | 107건 |

| 15 | 행사축제 | 7건 |
| 28 | 레포츠 | 10건 |

- 숙박(32) 제외 확정
- 수집 완료: `tourapi_raw/places.json` (383KB, 실패 0건)

### 사용 오퍼레이션

| 오퍼레이션 | 용도 |
|---|---|

| `detailCommon2` | overview, homepage 추가 수집 |
| `detailImage2` | 추가 이미지 수집 (firstimage 없는 장소) |
| `searchFestival2` | 행사축제 날짜 수집 |

## DB 스키마 (확정된 기준만)

기준 문서: 프로젝트 루트의 `schema.sql`, `schema.dbml`

### 테이블 목록

| 테이블 | 설명 |
|---|---|
| PLACE | 장소 기본 정보 |
| PLACE_IMAGE | 장소 추가 이미지 |
| PLACE_EMOTION_TAG | 장소별 감성태그 집계 |
| USER | 사용자 (카카오/구글 OAuth) |
| USER_PREFERENCE | 온보딩 스와이프 취향 점수 |
| PLACE_LIKE | 찜 |
| VISIT_LOG | 방문 기록 |
| LOG_EMOTION_TAG | 방문 기록별 감성태그 |
| COURSE | 여행 코스 |
| COURSE_PLACE | 코스 내 장소 순서 |

### 컬럼 매핑 규칙 (확정)
- TourAPI `mapx` → DB `lng` (경도)
- TourAPI `mapy` → DB `lat` (위도)
- PLACE upsert 기준: `content_id`

## PLACE.category Enum (확정)

`관광지` / `식당` / `카페` / `액티비티` / `문화공간` / `축제행사`

> 문화공간: 박물관, 미술관 등 포함. schema.sql ENUM 전환 필요.

## 기능 스펙

### 인증
- 소셜 로그인: 카카오, 구글

### 내 정보
- 이메일: 회원가입 시 소셜 이메일 그대로, 수정 불가
- 사용자ID: 중복 불가
- 닉네임: 중복 허용

### 내 취향 프로필
- 감성태그 6개 대분류 점수를 육각형 차트로 시각화
- '내 취향 다시 분석하기' 버튼 → 온보딩 재시작

### 온보딩
- 사용자에게 장소 사진을 보여주고 오른쪽(좋아요)/왼쪽(스킵) 스와이프
- **종료 조건** (둘 중 하나 충족 시 종료):
  1. 오른쪽 스와이프 누적 15개 도달
  2. 스코어 변화량이 임계값 이하일 때 조기 종료

> 조기 종료 임계값 수치와 사진 노출 알고리즘은 아직 미확정이며 `milestone.md`에서 관리.

## 감성태그셋

사진 분위기 기반으로 취향 파악 → 비슷한 분위기 장소 추천에 사용.

### 대분류 6개 (확정)

| 키 | 설명 |
|---|---|
| `relaxing` | 여유, 힐링, 조용함 |
| `lively` | 활기참, 북적임 (시장, 축제) |
| `romantic` | 데이트, 감성, 야경 |
| `local` | 동네감성, 숨은명소 |
| `photogenic` | 사진 찍기 좋은 |
| `style` | 역사/전통적인, 현대적인 |

### 소분류 12개 (미확정)
세부 목록은 확정 후 이 문서에 반영.
