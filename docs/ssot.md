## TourAPI (기준 정보)

- Base URL: `https://apis.data.go.kr/B551011/KorService2/`
- 안동시 코드: `lDongRegnCd=47`, `lDongSignguCd=170`
- API 키 위치: `.env` → `TOURAPI_KEY`

### 수집 대상 (contentTypeId)

| ID | 유형 | 건수 |
|---|---|---|
| 12 | 관광지 | 107건 |
| 14 | 문화시설 | 25건 |
| 15 | 행사축제 | 8건 |
| 28 | 레포츠 | 9건 |
| 38 | 쇼핑 | 27건 |
| 39 | 음식점 | 33건 |
| — | **합계** | **209건** |

- 숙박(32) 제외 확정
- 수집 완료: `data/raw/tourapi/places.json` (실패 0건)

### 사용 오퍼레이션

| 오퍼레이션 | 용도 |
|---|---|
| `areaBasedList2` | 장소 목록 수집 |
| `detailCommon2` | overview, homepage 추가 수집 |
| `detailImage2` | 추가 이미지 수집 (firstimage 없는 장소) |
| `detailIntro2` | 행사축제 날짜 수집 (searchFestival2는 지역코드 체계 불일치로 미사용) |

### 음식점 데이터 보완 (확정)

- TourAPI 음식점(39) 33건은 그대로 유지 (장소 자체 확장 안 함)
- tel 필드만 카카오 로컬 API(키워드 장소검색)로 보완 — 이름+좌표 기반, 이름 불일치 시 매칭 제외
- API 키 위치: `.env` → `KAKAO_REST_API_KEY`
- 지도/경로 기능에 쓸 API(TMAP vs 카카오)와는 별개 결정. 그건 아직 미정

## PLACE.category Enum (확정)

`관광지` / `식당` / `카페` / `액티비티` / `문화공간` / `축제행사`

## 기능 스펙

### 인증
- 소셜 로그인: 카카오, 구글

### 내 정보
- 이메일: 회원가입 시 소셜 이메일 그대로, 수정 불가
- 사용자ID: 중복 불가
- 닉네임: 중복 허용

### 내 취향 프로필
- 감성태그 7개 대분류 점수를 7각형 레이더 차트로 시각화 (0.5 중립 기준선)
- '내 취향 다시 분석하기' 버튼 → 온보딩 재시작

### 온보딩
- 사용자에게 장소 사진을 보여주고 오른쪽(좋아요)/왼쪽(스킵) 스와이프
- **종료 조건** (둘 중 하나 충족 시 종료):
  1. 최근 3장 벡터 변화량 평균 < 0.03 AND 최소 15장 진행 (수렴 종료)
  2. 총 25장 도달 (강제 종료)
  - 예외: 좋아요 3개 미만이면 최소 15장까지 강제 진행
- **카드 선택 전략**: 시드 7장(태그별 대표 1장) → 균형 60% + 탐색 30% + 랜덤 10%
- **벡터 업데이트**: 좋아요 학습률 0.40 / 싫어요 0.25 (상대적 업데이트 방식)
- 세부 명세: `server-back/Onboarding Algo.md` (v2.0.0)

### 장소 탐색
- 카테고리별 장소 목록을 카드 UI로 제공
- 장소 상세: 대표 이미지, 사용자 사진, 한줄 리뷰, 분위기 태그 확인 가능
- 행사·축제는 사용자의 여행 예정일과 기간이 일치할 때만 노출 (기간 한정 표시)

### 방문 기록
- 방문 장소에 사진 + 한줄 리뷰 남기기
- 업로드된 사진은 AI가 감성 태그셋 기준으로 분석 → 장소 분위기 데이터 보강
- 기록은 개인 로그 지도에 누적

### 지도
- **개인 로그**: 방문한 장소를 지도 위 핀으로 표시, 위치 기반 여행 기록 확인
- **유사 사용자 탐색**: 취향 분석 결과 기반으로 비슷한 성향 사용자의 여행 기록을 지도에서 탐색 (추천 점수에는 미반영, 참고 콘텐츠로 제공)
- **카테고리 탐색**: 카테고리별 장소 핀을 지도에서 탐색

### 코스 추천
- 스와이프로 가고 싶은 장소 선택 → 필수 방문 장소 지정
- 1일 코스 후보 3개 생성 (이동거리·카테고리 균형 고려)
- 숨은 장소 우선 반영 (방문 로그 수 적고 대표 관광지 아닌 장소)
- 코스 저장 가능 (장소 목록 + 방문 순서 보관)

## 감성태그셋

사진 분위기 기반으로 취향 파악 → 비슷한 분위기 장소 추천에 사용.
모든 사진과 사용자는 아래 7개 태그의 독립적인 0.0~1.0 점수 벡터를 가진다.

### 대분류 7개 (확정)

| 키 | 설명 | AI 판단 기준 (5가지) |
|---|---|---|
| `relaxing` | 여유, 힐링, 조용함 | 한적함 있음 / 조용한 분위기 있음 / 개방감 있음 / 자연 요소 있음 / 오래 머물고 싶은 분위기 있음 |
| `lively` | 활기참, 북적임 (시장, 축제) | 사람 밀집도 높음 / 활동적인 분위기 있음 / 상업적 활기 있음 / 축제·행사 분위기 있음 / 에너지 있는 분위기 있음 |
| `romantic` | 데이트, 감성, 야경 | 함께 시간을 보내기 좋은 분위기 / 따뜻한 색감 있음 / 아늑한 분위기 있음 / 감성적인 연출 요소 있음 / 특별한 추억을 만들고 싶은 분위기 있음 |
| `local` | 동네감성, 숨은명소 | 지역 고유의 분위기 있음 / 생활감 있는 공간 있음 / 지역 문화 요소 있음 / 지역만의 개성 있음 / 소박한 분위기 있음 |
| `photogenic` | 사진 찍기 좋은 | 좋은 사진 구도 있음 / 아름다운 배경 있음 / 매력적인 색감·조명 있음 / 시선을 끄는 포인트 있음 / 사진으로 남기고 싶은 장면 있음 |
| `traditional` | 전통적인, 역사적인, 한국적인 감성 | 전통적인 분위기 있음 / 역사적인 분위기 있음 / 한국적인 감성 있음 / 고즈넉한 분위기 있음 / 문화유산적인 분위기 있음 |
| `modern` | 현대적인, 세련된, 트렌디한 분위기 | 현대적인 건축 요소 / 도시적인 분위기 있음 / 세련된 디자인 / 트렌디한 공간 / 현대적인 감성이 있음 |

> `traditional`과 `modern`은 합이 1이 아닌 독립적인 점수. 한옥 카페처럼 두 태그가 모두 높은 복합 공간이 존재하기 때문.
